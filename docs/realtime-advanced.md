# 실시간 공동 편집 — 고급 기능 가이드

> **이 기능은 선택(고급)입니다.** Class Sync의 핵심은 CouchDB 기반 **파일 동기화**이며, 실시간 공동 편집 없이도
> 완전히 동작합니다. **먼저 파일 동기화를 성공시킨 뒤**(아래 [도입 순서](#권장-도입-순서)) 필요할 때 실시간을 켜세요.

실시간 공동 편집(Yjs)은 운영 난이도가 가장 높은 기능입니다 — 별도 서버·프록시·시크릿 관리가 필요합니다.
이 문서는 그 전제와 문제 해결을 한곳에 모읍니다. 서버 구축 자체는
[docs/Yjs 서버 운영/yjs-server-synology.md](Yjs%20서버%20운영/yjs-server-synology.md)를 따르세요.

---

## 권장 도입 순서

실시간을 처음부터 켜지 말고, 단계적으로 확장하세요(평가 보고서 권장).

1. **교사 1명 + 학생 1명**으로 개인 mirror 파일 동기화만 검증.
2. 첨부파일과 삭제/복원(`_삭제됨/`) 정책 검증.
3. 여러 학생으로 확장.
4. 공유 폴더(`share_*`) 배포 검증.
5. **여기까지 안정되면** 실시간 Yjs를 선택적으로 활성화.

## 전제 조건 (체크리스트)

실시간을 켜기 전에 아래가 모두 갖춰져야 합니다.

- [ ] **CouchDB 서버** — 파일 동기화에 이미 쓰는 중앙 서버(스냅샷 저장에도 사용).
- [ ] **Yjs WebSocket 서버** — 실시간 전용. 별도 프로세스로 상시 가동.
      ([docs/Yjs 서버 운영/yjs-server-synology.md](Yjs%20서버%20운영/yjs-server-synology.md))
- [ ] **HTTPS/WSS 리버스 프록시** — 모바일·외부 접속에 필수. `wss://`로만 접속하도록 구성.
- [ ] **HMAC 시크릿(`YJS_SECRET`)** — 서버 환경변수와 플러그인 ‘Yjs 공간 시크릿(HMAC)’에 **같은 값**.
      공유 공간별 서명 토큰이 발급되어, 토큰이 유출돼도 해당 공간 room에만 접근됩니다.
      서버는 placeholder 시크릿이면 기동을 거부합니다.
- [ ] **토큰 쿼리 로그 마스킹** — 토큰은 `?token=`으로 전달되므로, 리버스 프록시 접근 로그에 쿼리가 남지 않게
      마스킹/비활성화. 설정 방법은 [가이드 §9.1](Yjs%20서버%20운영/yjs-server-synology.md).
- [ ] **(Excalidraw만)** [Excalidraw 플러그인](https://github.com/zsviczian/obsidian-excalidraw-plugin) 설치.
      그림 실시간은 `.excalidraw.md` 형식만 지원하며, 미설치 시 해당 기능만 자동 비활성화됩니다.

## 켜는 순서

1. 서버에 `YJS_SECRET`을 설정하고 가동(기동 로그에 `auth: hmac (per-space)` 확인).
2. 플러그인 설정 → **Yjs 서버 URL**(`wss://…`)과 **Yjs 공간 시크릿(HMAC)** 입력 → 실시간 켜기.
   토큰·시크릿은 **Obsidian Secret Storage**에 저장됩니다(`data.json` 평문 아님).
3. 공유 공간을 **배포**하면 공간별 서명 토큰이 학생에게 자동 전파됩니다.
4. 멤버 변경/시크릿 교체 후 **재배포**하면 토큰이 갱신됩니다. ‘공간 토큰 만료(일)’로 TTL 설정 가능.

## 문제 해결 (troubleshooting)

| 증상 | 점검 |
|---|---|
| 실시간이 연결되지 않음 | ‘종합 진단 실행’의 실시간 항목 — `url=설정됨`, 공간별 `spaceToken=설정됨`인지. 서버 기동 로그의 `auth` 모드. |
| 토큰은 있는데 거부됨 | 플러그인 ‘Yjs 공간 시크릿’과 서버 `YJS_SECRET`이 **정확히 동일**한지. 공간 **재배포**로 토큰 재발급. |
| 모바일에서만 안 됨 | `wss://`(보안) 사용 여부. 프록시가 WebSocket Upgrade 헤더를 전달하는지. 인증서 유효성. |
| Excalidraw 실시간 안 됨 | Excalidraw 플러그인 설치 여부. 파일이 `.excalidraw.md` 형식인지(순수 `.excalidraw`는 미지원). |
| 편집은 되는데 저장이 안 퍼짐 | 세션 종료 시 CouchDB 스냅샷이 저장됨. ‘세션 중 스냅샷 주기(초)’를 켜면 닫기 전에도 주기적으로 반영. |
| 접근 로그에 토큰이 노출 | 프록시 로그 마스킹([가이드 §9.1](Yjs%20서버%20운영/yjs-server-synology.md)). 토큰은 WSS로만 전송. |

## 보안 메모

- 실시간 토큰/시크릿은 절대 저장소(공개 레포·설정 내보내기)에 평문으로 남기지 마세요 — 플러그인은 이를
  Secret Storage에 보관하고 설정 내보내기에서 제외합니다.
- 레거시 전역 토큰(`YJS_TOKEN`, 시크릿 없음) 모드도 지원하지만 **공간별 격리가 없으므로** HMAC(`YJS_SECRET`) 방식을 권장합니다.

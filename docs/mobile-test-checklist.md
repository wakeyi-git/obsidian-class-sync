# 모바일 검증 체크리스트 (iOS / Android)

배포 전 실기기에서 수행. 교사 기기 1대 + 학생 기기 1~2대(또는 데스크톱과 혼합) 권장.
각 항목 통과 시 체크. 실패하면 로그 패널(🔄)과 "종합 진단 실행" 명령으로 원인 확인.

## 설치 / 로드
- [ ] Obsidian 버전 ≥ **1.11.0** (minAppVersion).
- [ ] 플러그인 활성화 → 콘솔 오류 없음.
- [ ] 설정 탭이 그룹(.setting-group) 레이아웃으로 정상 렌더, 추가 버튼 풀폭.

## 온보딩 (학생)
- [ ] 교사가 학생 "초대" → QR 모달 표시(SVG QR 정상).
- [ ] 휴대폰 기본 카메라로 QR 스캔 → `obsidian://class-sync-invite` 딥링크로 Obsidian 열림 → 자동 설정.
- [ ] 초대 코드 붙여넣기 경로도 동작.
- [ ] 학생 계정은 자기 mirror DB에만 접근(타 DB 403).

## 개인 미러 동기화
- [ ] 학생이 노트 생성/수정 → 교사 vault 학생 폴더에 반영(양방향).
- [ ] 이름변경/이동 반영, 삭제 시 보관 폴더로 이동.
- [ ] 첨부(이미지·PDF) 동기화, **대용량(최대 크기 초과) 파일은 즉시 스킵**(메모리 급증 없음).
- [ ] 오프라인 편집 → 재연결 시 큐 업로드.
- [ ] 같은 파일 동시 편집 → 충돌 보존(_충돌/) + 충돌 목록에서 해소.

## 공유 / 실시간 / 피드백
- [ ] 공유 공간 배포 → 학생 vault에 공유 폴더 자동 생성.
- [ ] 같은 공유 문서 동시 편집 → 글자 단위 실시간 반영, 서로 커서·이름 표시.
- [ ] 세션 종료 시 스냅샷 저장(+스냅샷 주기 설정 시 세션 중 반영).
- [ ] 피드백 추가(선택 영역) → 패널 표시 → "위치로" 한 번에 이동 → 해결/삭제 동기화.

## 모바일 절전
- [ ] 앱을 백그라운드로 → 로그에 "동기화 일시정지", 복귀 시 "재개"(토글 ON 기준).
- [ ] 토글 OFF 시 백그라운드에서도 정지하지 않음.
- [ ] 모바일에서 편집 후 업로드가 `mobileDebounceMs` 지연 후 발생.

## 운영
- [ ] 설정 내보내기 → JSON에 비밀번호·토큰·학생 비밀번호·deviceId 없음.
- [ ] 설정 가져오기 → 학생·공유·옵션 복원, 기존 자격증명/역할 보존.
- [ ] "종합 진단 실행" → 서버 도달 + 내 DB 읽기/쓰기 OK + 실시간 상태 로그.

## 성능 / 배터리 (체감)
- [ ] 장시간 사용 시 과도한 발열/배터리 소모 없음.
- [ ] 큰 vault에서 시작 시 전체 재업로드 폭주 없음(layout-ready 이후 감시).
